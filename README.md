# GlassReflex releases

Downloads of [GlassReflex](https://glassreflex.app), liquid glass for your Mac cursor.

This repository holds only the release files. The source code of the app is not public.

- **Get the app:** [glassreflex.app](https://glassreflex.app). The download button there always points to the latest release.
- **Updates:** GlassReflex checks for new versions by itself and asks before installing. You can also choose Check for Updates… in its menu.
- **Requirements:** macOS 26 or macOS 27, Apple silicon or Intel.
- **Support:** [support@glassreflex.app](mailto:support@glassreflex.app)
